🔧 Troubleshooting

If localhost:8000 doesn't work, try:

  • Make sure the system is running: ./start_money_maker.sh
  • Try 127.0.0.1:8000 instead of localhost:8000
  • Check if another application is using port 8000
  • Restart your browser
  • If in a container/VM, use the container's IP address
